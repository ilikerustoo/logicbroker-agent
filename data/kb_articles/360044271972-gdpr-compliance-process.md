# GDPR Compliance Process

## 

If a customer would like you to remove their personal information from the system, the process is as follows:

Find the "Complete" order - Order must be fulfilled/complete, or in a failed/ignored status (status code greater than 1000)

From the more actions drop down on the order, there will be an option to "Remove Personal Data". This action will remove names, street address from standard address fields for that order, as well as any documents linked to that order (Shipment, Invoice, etc.)
