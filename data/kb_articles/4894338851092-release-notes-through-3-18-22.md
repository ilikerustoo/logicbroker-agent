# Release Notes Through 3/18/22

## 

## Portal Updates:

  * New portal users will be directed to Learn Logicbroker upon registering
  * Onboarding: 
    * Support for New Submission Notification 
    * Email notification on first order
  * CustomJSON:
    * New directories are available on VFTP

    * File grabber job
    * Support for export workflows
  * Inbound JSON support for inventory
  * Support for CustomXML output valid JSON from templates
  * Flat files: Allow template to specify flipped company ids
  * Ability to split a return request from a retailer into an individual return request for each purchase order

  * Ability to support retailers sending in a cancellation request for a sales order instead of a purchase order

  * Ability to mark a marketplace order as delivered via API
  * Ability to check order delivery status via API for marketplace



## Connectors: 

  * Support for BackMarket Connector
  * Support for Rakuten Connector
  * Amazon: Ability to switch fulfillment for inventory posting 
  * ShipEngine: Ability to include customs information




## Learn Logicbroker:

  * Addition of sign out button
  * Default assignments are automatically generated upon logging in for suppliers
  * Reminder notifications will trigger when an assignment is nearing its due date 



## Bug Fixes:

  * BackMarket: Fix for remorse pull window
