# Release Notes thru 5/30/2018

## 

**New Features:**

  * Update to 860 process, will check all Item Identifiers for matching instead of Line Number, if there are no matches or duplicate matches the Order will get marked as failed.
  * Duplicate documents will not get created as documents in "Duplicate" (1300) status. 
  * Create cancellation from orders from EDI with a cancellation code.
  * Shipments will not auto-populate boxes with Qty left to ship being "0"



**Fixes/Updates:**

  * Tracking Upload on Order Management will do duplicate checking
  * Tracking upload validation on format
