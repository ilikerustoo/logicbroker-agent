# Release Notes Through 9/28/22

## 

## Portal Updates:

  * UI Enhancements to reflect branding updates 
  * Support for informative events when any changes are made to configurations on inventory feeds 



  * Onboarding: 
    * Ability to ignore/hide integrations that a retailer would no longer like to pursue
    * Remove duplicate company name field and automatically populate from the initial company information page
    * Improved landing page with messaging about creating a new account or connect using an existing account



  * Manage Users: 
    * Ability to export user management page which includes the user and their permissions
    * To update inventory settings, users will need the settings/manage permission



## Connectors:

  * Fields will be left blank when we pull inventory from API, if no value is provided forCost, RetailPrice or MSRP
  * NetSuite Supplier Bundle: Add timezone date fix for all custom fields
  * SKUVault: Support for cost on inventory fields 
  * ShipStation: Support to retry posting orders on status 502 and 504



## Learn Logicbroker/Help Center:

  * Added Quickstart Guides to the Help Center Sidebar for easier navigation 
  * Enhancements to content placement for accordion sections
