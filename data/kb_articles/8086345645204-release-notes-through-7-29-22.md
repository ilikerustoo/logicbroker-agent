# Release Notes Through 7/29/22

## 

## Portal Updates:

  * Onboarding: 
    * Ability to send integration invitations in bulk
    * Ability to export onboarding tickets as a CSV file
    * Support for integration priority and go live date on all integrations
  * Inventory: 
    * Ability to download all inventory across enabled suppliers
  * Order Sourcing: 
    * Prevent sales order total amount from being copied to POs




## Connectors:

  * BigCommerce: 
    * Support adding new variants to existing products
    * Ability to block sending retail price on inventory
  * eBay: Support for more special characters in the product feed
  * DSCO: Add ship from address to the shipment map
  * ShipBob:

    * Add invoice_amount to the shipment map

    * Warning log for orders that failed to pull to shipment
  * Doba: Map itemSubDisCount on Invoices




## Learn Logicbroker:

  * Support for more robust search functionality
