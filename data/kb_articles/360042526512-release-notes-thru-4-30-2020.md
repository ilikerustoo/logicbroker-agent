# Release Notes thru 4/30/2020

## 

## Portal Updates:

  * EDI: Support Inbound 875 Map
  * Portal refresh notification when changes are made
  * Table view for shipment details page when containers exceed 6
  * Add error message for retailers accessing default address and payment terms settings
  * EDI: Processing inbound PO Change (860) will update status and scheduled ship dates on the original order



## Connector Updates:

  * Shopify: Add mapping for ClassCode, ShipmentCost, ServiceLevelDescription on Orders to Shopify
  * Shopify: Map Variant ID to UPC on outbound shipments from Shopify
  * API Connector: Direct Integration with Kohls, Nordstrom, Neiman Marcus, Chewy
  * API Connector: DCL Logictics (3PL Fulfillment)
  * Shipstation: Check for duplicate orders before creating an order in Shipstation
  * AmazonFBA: Add invoice integration for financial events for shipped orders
  * Amazon Seller Central: Increase number of checks to validate sending inventory feeds
