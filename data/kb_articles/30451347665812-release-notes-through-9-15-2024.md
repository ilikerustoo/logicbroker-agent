# Release Notes Through: 9/15/2024

## 

Portal:

  * **Dashboard:** Customizable reporting for users 
  * **Order Management:** Failure reasons are now visible on the partner side so retailers can help with resolution
  * **Partner Management Center:** Support for time picker when pausing suppliers
  * **Product Management Center:** Update to error messages for taxonomy import to make them more clear**  
**
    * Include supplier name on products in my catalog
    * Visibility into listed by and date and delisted by and date on the product page in my catalog
    * Messaging in the portal to indicate when conditional fields are required 
    * Improved page formatting to help with responsiveness
    * Optional parent SKU filter parameter on the /Products endpoint to support faster performance
  * **Onboarding:** Ability to customize the link to the onboarding documentation in the onboarding email 
    * Update the supplier account live email to be more clear when they create an account
    * Update verbiage on the Shopify connector to include product and inventory 



Connectors:

  * **BigCommerce:** Support for pulling in shipping costs on orders 
    * Update order in BigCommerce to support returns
    * Pull in width, height, and depth on orders
  * **Walmart:** Support pulling cancellations for WFS
  * **Shopify** : Remove compare_at_price if missing in POC
    * Fix for filtering list of cancels vs. returns to reduce errors
    * Support to pull returns in from Shopify
  * **Marketplacer** : Ability to process returns through the connector 
    * Pull buyerEmailAddress when getting orders 



Fixes:

  * **Product Feeds:** Avoid enclosing fields in quotes if they contain commas
  * **Connected Commerce Network:** Profile Cards are Showing when profile is unchecked 
  * **Product Onboarding Center:** Dashboard Total Products Available Reflecting My Catalog 
    * Error Messaging Missing on Import
    * Page Goes Blank After Attribute Mapping
    * Changes to Parent SKU details does not put all products in an Update Suggested status
    * Supplier products are failing with no messaging on why
    * Error when supplier creates/updates item with auto approval on
    * Messaging around duplicate SKUs
    * POC Bulk Approval Not Working Correctly
