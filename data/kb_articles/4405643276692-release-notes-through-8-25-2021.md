# Release Notes Through 8/25/2021

## 

##### Portal Updates:

  * Portal:
    * Support for different currency symbols based on the currency field
    * Support for custom lookup tables for billable users to manage information such as ShipStation Store IDs in the portal.


  * Product Catalog:  

    * Catalog set up wizard is available for suppliers to easily map products to meet retailer specifications.



##### Learn Logicbroker Updates:

  * Homepage: 
    * Paths have been renamed to degrees, modules have been renamed to classes, and sections have been renamed to assignments.
    * The homepage is now more user-friendly, assigned classes are displayed as tiles. This is also how favorited content will appear. All other classes are available under the "Explore Degrees" and "Explore Classes" at the top of the page.
  * Support for feedback directly in Learn Logicbroker with the use of appcues. 
  * Responsive web design provides users with the ability to complete assignments on any device.
  * The search engine is more robust and will provide more details for users, making it easier to find what is needed.
  * 


##### Connector Updates:

  * Support for Lazada marketplace connection
  * Support for Shopee marketplace connection
