# Release Notes Through 11/1/22

## 

## Portal Updates:

  * User Management: Support for multiple email addresses on the invite page
  * Order Management: Tracking import will now show a pop-up with a short description of the required fields as well as the file dropper



  * Knowledge Base: Companies linked to a single retailer with a custom help center will also have access to the Logicbroker Knowledge Base



  * Product: 
    * Support for image size limit of 10 MB
    * Ability to store large string text fields
    * Apply filters from the default export template when auto-exporting to retailers

  * Scheduled Tasks: More uniform and concise messages for example: 

"EDI File Grabber Job Failed"

  * VFTP Directory: Support for file listing limit of 10,000



## Connectors:

  * Shopee: Inventory and product have been updated to V2
  * ShipStation: Add imageUrl to order map
  * New Hawk: Support different quote ids for discounts
  * eBay: Ignore duplicate aspect names, will take only the first value
  * Airpoints Mall - New Zealand: New Marketplace Connector that supports orders, shipments, and products 
  * Shopify: 
    * Allow multiple inventory locations
    * Provide acknowledgement post



## Learn Logicbroker:

  * Support for cookie preferences
  * Awarded certificate upon completion of degrees/classes 



## Bug Fixes:

  * Filtering for partner ship methods
  * Updating inventory clear after and full feed settings
