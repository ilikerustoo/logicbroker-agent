# Release Notes Though: 9/22/2023

## 

## Portal:

  * **Message Center:** Ability to export data showcased on the Messages page
  * **API:** Support for attaching a single file to multiple documents through the API endpoint [/api/v2/Attachments](https://stage.commerceapi.io/swagger/ui/index#!/Attachment/Attachment_Upload)
  * **Onboarding** : Showcase account type, new or existing, to form summary

  * **VFTP** : OutboundByPartner directories for CustomXML

  * **Invoices:** Ability to block suppliers from sending duplicate invoice numbers across orders



## Connectors: 

  * **Netsuite Supplier Bundle:**
    * Add support for pallets in Logicbroker Packages
    * Support Promotions/Discounts
    * Support for document flow control
