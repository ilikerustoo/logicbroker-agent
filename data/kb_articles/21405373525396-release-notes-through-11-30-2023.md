# Release Notes Though: 11/30/2023

## 

Portal:

  * **Navigation:** Updated pagination to support jumping to first/last page in areas including orders, inventory, events, messages, etc. 
  * **Order Management:** Ability to bulk cancel orders 
  * **Events** : 
    * Display user name on documents created in the portal 
    * Email notifications to retailers and suppliers when the order has been sent 
  * **Invoices** : Support for automatically generating branded invoices
  * **EDI:**
    * Improved error handling for large documents 
    * Support for self-service EDI connection setup and maintenance 



## Connectors:

  * **Shopify** : Support for partial cancellations 
  * **Shopee** : Improved visibility into authorization error handling 



## Fixes:

  * None
