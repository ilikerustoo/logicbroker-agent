# Release Notes Though: 7/3/2023

## 

## Portal:

  * **Ship Method Mappings**
    * Ability to download entries from the partner ship method mapping table

    * Include "Your Code" in partner ship methods table to help with reconciliation 

    * Include "Used By Partner" flag in ship method export
  * **Order Management**
    * Ability to configure retailer validation to block partial shipments on the line level
    * Bulk Picking & Shipping: 
      * Support to filter orders by SKU and requested ship date
      * Improved label generation time through updated PDF format
      * Show progress percent when downloading from bulk pick
  * **User Permissions:** Include details about each permission type and its function 
  * **On-Demand Onboarding:** Showcase the supplier's companyId on the integrations page 



## Connectors: 

  * **Shopify** : Update to stop pulling in SKUs that are in a draft or archived status 
  * **Tokopedia** : Support for handling large prices
  * **ShipEngine:** Pass order RequestedShipDate as ship_date when generating labels
  * **The Market:** Marketplace connector that supports shipments, acknowledgments, inventory, and product catalog. The connect receives orders and acknowledgments.
