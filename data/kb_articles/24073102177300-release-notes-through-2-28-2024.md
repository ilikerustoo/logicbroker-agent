# Release Notes Though: 2/28/2024

## 

Portal:

  * **API** : Default to V2 endpoints on the [swagger documentation ](https://stage.commerceapi.io/swagger/ui/index)and added new V2 endpoints for V1 
  * **Onboarding** : Ability to make the core inventory onboarding step configurable based on retailer 
    * Indicate when inventory needs to be reuploaded by partner
  * **Events** : Link document id on the events page 
    * Support for exporting events into an excel file
    * Link document on email event notifications
  * **Product** : Download XLSX instead of CSV on product feeds 
    * Support for uppercase and lowercase string transformation
  * **Inventory** : Vendor Sourcing through Inventory Feed Settings Vendor #
  * **Messaging** : Bulk change status on messages in the portal
  * **Users** : Visibility into the last login and created date on the user list



## Connectors:

  * **Shopify** : Update to API version 2024-01 
    * Ignore archived SKUs when sourcing/posting orders
    * Support for supplier's Shopify order routing rules when posting orders
  * **SkuVault** : Set WarehouseQuantity to 0 if Quantity is 0 
  * **Lazada** : Updated to public application
  * **Santander** : Support delisting products
  * **NEXUS/MRI:** Connector that helps with accounts payable. This connector accepts invoices.
  * **GoFlow** : Webstore connector that accepts shipments and inventory. The connector provides orders.



## Fixes:

  * Show users in groups containing unrelated companies on the users page
  * Enhancements to text wrapping in Portal fields
