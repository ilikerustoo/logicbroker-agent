# Release Notes thru 1/12/2018

## 

**New Features:**

  * Automated integration testing program for retailer and suppliers is available
  * Multi-supplier inventory processing using same merchant SKU from multiple suppliers.
  * Advanced export limit increased to all documents available.
  * Importing report configuration does not overwrite existing reports, just adds new ones.
  * Drop ship order sourcing by supplier inventory cost is now available.

none
