# Release Notes thru 06/11/2019

## 

## New Features

  * Estimated Delivery Date available in Advanced Analytics
  * Support Return Requests and Approvals
  * Sourcing priority setup based on supplier scorecard when item cost is the same.
  * Allow suppliers to default Remit To Address and Payment Terms for Invoicing.
  * Prevent users from creating parent containers with items in it.
  * Add remittance address on the Invoice Details page.
  * Add Company Profile under Account Information page.
  * Add merchant name on Shipment Creation page for ship engine and easy post connections.
  * eBay added to Connections page.
  * Support pulling Cancellations from Shipstation.
  * Quickbooks connector added to Connections page.
  * Add destination liftgate and residential accessorials to Convey connector. (Destination Liftgate? And Destination Residential? KVPs)



## Fixes

  * Fix ChangeReason to Bulk Cancellation page.
