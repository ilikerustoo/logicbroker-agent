# Release Notes Through 10/27/21

## 

## Portal Updates:

  * **Product Catalog/Feed:**
    * Maximum upload time in place, an error message showcasing the number of successful items at time out
    * New attributes, Origin Country and Product Care, were added 
    * Support for more relaxed validation for product feeds 



## Connector Updates

  * **ShipEngine** : Addition of GLSP-GR ship method mapping 
  * **Shopify** : Support to configure an order remorse period 
  * **Netsuite** : 
    * Supplier Bundle: Ability to map to Logicbroker packages when pick/pack/shipped is enabled
    * Supplier Bundle: Support for a second tax field on invoices 

  * **Wayfair API** : Support for retry logic for 500-level errors 
  * **eBay** : Support item groupings in the product feed
  * **Incomm** : Added as a new e-certificate connector
