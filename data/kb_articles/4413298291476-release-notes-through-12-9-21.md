# Release Notes Through 12/9/21

## 

## Portal Updates:

  * **GDPR** : Email addresses will be removed even without a first and last name present
  * **Returns** will no longer include lines with 0 quantity
  * **Invoices** created from sales orders will not include canceled items
  * **Product Catalog/Feed:**
    * Support for default values in advanced import
    * VFTP: Support for catalog broadcast and default import template
    * Ability to automatically export catalog to retailer upon import completion 
    * Profile configurations available to import/export catalogs 
    * Support for export based on last_update 
    * Automatically send product feeds to partner



## Connectors:

  * **eBay** : Fixed refund amount for posting returns
