# Release Notes thru 10/28/2019

## 

## New Features

  * Add OrderNumber and PartnerPO when multi-invoicing off of the shipment.
  * Show requested ship method when creating a shipment in the portal.
  * Add Connected Commerce Network (CCN). 
    * Ability to create a public profile and product show case to display to other CCN retailers or suppliers.
    * Send message to available suppliers and retailers, requesting to connect.
  * Support IB 820 Payment Remittance. Maps to invoice document, sent from retailer to supplier.
  * Magento 2: Added option to invoice the entire order once the first shipment has been received.
  * Setting up default vendor numbers for inventory feeds.



## New Connections

  * New Marketplace: Google Shopping Actions
  * New Supplier: Hello Extend
  * New EDI Retailer: Hubert



## Fixed

  * Ship Engine: Failure to create shipments with extra characters in name; characters will be removed when processing.
