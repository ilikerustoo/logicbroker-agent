# Release Notes Through 4/30/2025

## 

### **Portal**

**Product Onboarding Center:**

  * Improve performance of taxonomy bulk update tasks to handle at least 10k entries
  * Add Button to UI for fully clearing Categories, Attributes, Attribute Sets
  * Support larger text boxes to show all character



**Events**

  * Show username and company
  * Show connector name in details for alerts/errors
  * Improve usability



**Login/Environment Page** :

  * Environment Page Update to match new styles
  * Sign In Again Update
  * Log In Page Update
  * Reset Password Page Update



**On-Demand Onboarding:** Support for additional custom fields

**Inventory:** Improve UX on Inventory Page

**Bulk Pick:** Update to Bulk Pick to Select Multiple Options

**Boxes** : Support for defaulting first box in portal to "Pallet" on Shipments for freight Orders

### **Connectors**

**Shipengine** :

  * Update connector to enforce 2 character country code
  * Support for International Orders



**BliBli** : Change PO Number

**Airpoints** : Add User-Agent header on requests to Airpoints

**Kibo** : Support for Kibo connector

**Shopify** : Update SKU lookup to support Shopify's lack of exact matching

**Shoppee** : Annual acknowledgement of Data Protection Policy

### **API**

**Product Onboarding Center** : Add API for fully clearing Categories, Attributes, Attribute Sets

**Inventory** :

  * Endpoint for setting quantity to zero
  * New export endpoints to support new UI



### **Fixes**

**Inventory** :

  * Continue after validation warning on inventory upload
  * Unable to Delete Item After Zeroing Out
  * Inventory V2 not showing error events
  * Inventory edit pulling empty string into null field



**Partner Management Center** : Shows different scores in different views

**Product Onboarding Center** : Filters not showing count for non-syndication suppliers
