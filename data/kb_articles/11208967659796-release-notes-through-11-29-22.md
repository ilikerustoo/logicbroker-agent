# Release Notes Through 11/29/22

## 

## Portal Updates:

  * Support to run workflows on scheduled tasks page in our Stage environment to help accelerate testing 

  * The on-demand onboarding page is only available for billable retailer companies

  * Ability to pull scorecard data via API using the endpoint [api/v1/partners/scorecards](https://stage.commerceapi.io/swagger/ui/index#!/Partner/Partner_GetScorecards) and takes these parameters:

    * startDate

    * endDate

    * includeBlank (includes cards without data like on the portal page)

  * Save hidden/shown table columns by bookmarking the URL

  * Remove PostScript as an option for labels/packing slips




## Connectors:

  * Shopify: Modification to API error messages to shorten response body



## Fixes: 

  * API: Fix availability for SKUs with slashes
  * Shopify: Fix for Shopify changing last update times on orders
  * eBay: Fix for pulling offers for SKUs with slashes
