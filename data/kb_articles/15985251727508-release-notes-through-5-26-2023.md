# Release Notes Though: 5/26/2023

## 

## Portal:

  * **Order Management**
    * Bulk Picking & Shipping: 
      * Updates to support sorting by ship to state, arrival type, requested delivery date
      * Support for sender class code for label sorting and picklist grouping
      * Simplified pick list headers 
    * Ability to configure auto-cancellations from the retailer to a supplier who do not ship on time 
  * **Inventory:**
    * Automation for clearing warehouse quantities to prevent stale inventory
    * Improved error handling for SKUs with tabs or newlines 
  * **Testing:** Support for Retailer-Initiated Order Changes (EDI 860s) in test cases 
  * **Monitoring Report:**
    * Updated Download option to read "Download Report" 



## Connectors: 

  * **SKUVault:**
    * Ability to sum warehouse locations across locations 
    * Display warehouse locations with a quantity of 0 instead of just in-stock items 
  * **Shopify**
    * Map variant price to cost on inventory
    * Map currency on orders
    * Pull inventory quantities by location for supplier
