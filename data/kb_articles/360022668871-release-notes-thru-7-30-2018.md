# Release Notes thru 7/30/2018

## 

**New Features:**

  * Ability to export and upload Shipment Settings mappings
  * Ignore end of file CSV if column values are empty.
  * If wrong columns are provided in inventory upload a detailed message will be provided.
  * Ability to resend all existing inventory as a new update.
  * Sales totals will be visible on the partner score card.
  * Download postage/shipping labels using Ship Engine.
  * Use one configured retailer account to create labels/postage for all connected suppliers.



**Fixes/Updates:**

  * New test orders created will mark the old one as ignored.
  * Validation and business rule failures during testing will link to the associated order.
  * Import tracking allows for multiple boxes and reports failures with better detail.
