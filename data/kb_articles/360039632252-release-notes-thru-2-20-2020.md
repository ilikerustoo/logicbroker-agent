# Release Notes thru 2/20/2020

## 

## Portal Updates:

  * Filtering on Requested Ship Date
  * Advanced Import: Mapping wizard for custom CSV document uploads
  * Account Information: Manage default return addresses
  * Attachments: Users sending 846 documents can now view and download the raw outbound 846 EDI
  * Improved drop ship sourcing logic allowing for custom purchase order sourcing rules to be configurable
  * Defaulting unique Acknowledgement, Shipment, and return numbers when documents are submitted through portal.
  * Notification for orders reaching their RequestedShipDate 
    * Overdue 72 Hours Overdue to Ship is the name of the monitoring configuration
  * Warning provided when scientific notation is provided on all CSV import (inventory, orders, acknowledgements shipments, invoices, and returns)



## Connector Updates:

  * MCOM: Inventory Update using multiple warehouses from one feed
  * Magento 2 Extension 1.1.4 Release 
    * Move cron jobs in separate processes
    * Add index on the SKU column in the temporary inventory table
  * ShipEngine: Allow package edits for failed label creation
  * ShipEngine: Add Fedex Home Delivery to Map

None
