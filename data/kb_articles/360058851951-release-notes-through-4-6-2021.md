# Release Notes Through 4/6/2021

## 

#### Portal Updates:

  * Failure Alerts link to Event Details
  * Purchase Order Numbers are now visible on Shipment and Invoice Exports from the Dashboard

  * Access to Event Details from the Failed Document Page



#### Connector Updates:

  * **DSCO** :   

    * Add cancelledReason to acknowledgment map
    * New Retailers, REI and Bass Pro Shops, added
    * Connector authorization based on Retailer ID
  * **Amazon** : 
    * Improved shipment error handling for Seller Central
  * **Wayfair** :
    * Incorrectly Failed Acknowledgments
    * Register Shipment as Configuration
  * **NetSuite** :
    * Retailer item pricing used on sales orders
    * Pull shipFrom information based on location
    * Added additional custom fields for POAck functionality
    * Support for attaching Packing Slips to sales orders
  * **Walmart Marketplace:**
    * Support for cancellations
  * **Shopify Supplier Flow:**
    * Shopify tags to order on the header level**  
**
    * UPC added to inventory map from barcode



#### Bug Fixes:

  * **Portal** :  

    * Fix error messages on business rules on the document standards page
