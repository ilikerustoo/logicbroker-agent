# Release Notes thru 03/21/2019

## 

## New Features

  * Ability to export documents via CSV/XLSX from the Search page.
  * Pull "Ship From Address" from Shipstation based on a warehouse lookup.
  * Configurable Shipment SLA for Scorecards - shipment window (hours) and percent cancelled.
  * Configurable weights for scorecard calculations - Cancel Percent, Shipment Percent and Shipment time weightings.
  * Ability to Cancel orders in a "Failed" status.



## Fixes

  * Fix date requirements in testing to exclude minimum dates.
