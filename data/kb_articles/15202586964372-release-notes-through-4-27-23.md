# Release Notes Through: 4/27/23

## 

## Portal:

  * **Order Management:**
    * Support for Wave Picking & Shipping
    * Set default ship from address, if populated, automatically on the order
    * Export labels in the order their ids were passed to the API endpoint.
  * **Inventory:**
    * Support for retailer-specific inventory templates 
    * Ability to support specifications to provide validation around the submission
    * Ability to create optional fields on the validation rules 
    * Updated email template to provide more direction around fixing inventory failures 
  * **Product Catalog:** Mapping for imported catalog columns
  * **Onboarding** : 
    * Retailer visibility into supplier progress
    * Ability to collect vendor number on the initial form 
    * Support multiple onboardings under the same email
    * Resend onboarding invitations



## Connectors: 

  * **Shopify** : Updated to API Version 2023-04, all shipments will move through the Use Fulfillment Orders Flow 
    * Support for updating Shopify inventory locations based on warehouse and warehouse quantity from our inventory fields
  * **Lazada** : Change shipment and delivery notices to use the new Fulfillment API
  * **Tokopedia** : Support for accepting or ignoring price updates on inventory
  * **DSCO** : Change OrderNumber to map from poNumber
  * **eBay** : Allow delisting through the product feed
  * **Wayfair** : Support for Full Feed Inventory Paging 
  * **TikTok:** Add region/country codes to order map



## Bug Fixes: 

  * Payment amount mapping on invoices
  * Invoice total rounding error
