# Release Notes thru 03/24/2017

## 

**New Features:**

  * New scorecard pages for both retailers and suppliers. 
  * Users can review shipment grades for all their partners and receive email notifications on them.
  * Support mapping/configuring for positional file formats.
  * V2 API endpoints now support getting lists and details of all documents in one call. Documents include Order, Acknowledgement, Shipment, Invoice, and Return. 



**Fixes/Updates:**

  * Order Management Page - Selecting and printing packing slips for multiple partners will download and combine selection in one document file keeping each partner's specific format.
