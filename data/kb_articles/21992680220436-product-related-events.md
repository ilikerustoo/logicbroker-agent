# Product Related Events

## 

**Audience :** All users

The Events page of the Product Onboarding Center provides users with visibility into all activities within Logicbroker or a related system. These events can be informational such as items syncing with other systems i.e. BigCommerce or they can be alerts indicating further action is needed such as items failing validation.

**At a Glance**

**Date**

Date and time (in your time zone) the event took place

* * *

**Severity**

The type of event - this will show you if it is an **Alert** or **Info**

* * *

**Summary**

The summary of the event

* * *

**Details**

This is where you can find more information around the event such a the user who took the action, the file name, etc. 

* * *

**Viewed**

An indication of whether an event was viewed or not - to mark as viewed either click on the viewed checkbox or click the **View** button

* * *

**View**

This button will display more details on the event such as users, file names, updates, the error and more

**Display**

**Filter results**

Click on the filter icon to apply a filter to your events. Select the field you want to filter by, the operator, select the value from the list, and then click Apply.

Once a filter is added, you will see a number next to the filter icon. Filters can be stacked, so add new filters or remove them by clicking the trash can next to the filter and then click Apply.
