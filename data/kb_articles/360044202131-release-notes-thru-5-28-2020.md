# Release Notes thru 5/28/2020

## 

## Portal Updates:

  * Allow users to log in to SFTP/FTP with CoId (Account Number) and subscription key (API Key)
  * Add Advanced Analytics User Permission (analytics/manage)
  * Bulk Actions: Add QuantityBackordered on when bulk acknowledging
  * Add Acknowledgement Request in Portal 
    * Acknowledgments being sent from the retailer
  * Support IB 945 EDI
  * Configure default default cancel codes (ChangeReason) on the acknowledgement and return reason codes (ReturnReasonCode) on the return documents. 
    * Configured under Account Information, available for only supplier accounts.
  * Configure default ScheduledShipDate calculated from the acknowledgement DocumentDate 
    * Configured under Account Information, available for only supplier accounts.



## Bug Fixes:

  * Bulk Actions - Deducting cancelled quantities automatically when shipping
  * Processing 820s with over 100 items 
    * Items are replaced with a placeholder and details will be provided in Event
